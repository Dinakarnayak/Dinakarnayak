# Research & Engineering Projects

A curated index for the systems highlighted on the Dinakar profile.

## PolicyGuard AI

**Focus:** explainable NLP, policy analysis, risk scoring, uncertainty, and evidence-aware decisions.

**Research questions:** Can clause-level evidence and calibrated confidence make automated policy-risk analysis more transparent and useful than opaque classification alone?

## MedFusion-X

**Focus:** multimodal medical AI, adaptive fusion, modality disagreement, uncertainty estimation, and experiment telemetry.

**Research questions:** When should a multimodal system trust one modality, combine modalities, or abstain because the evidence conflicts?

## TraceLens Agent Observability

**Focus:** AI-agent tracing, evaluation, latency, failures, token usage, cost, and reproducible output assessment.

**Research questions:** How can structured observability expose reliability failures that aggregate success rates hide?

## Autonomous AI Coding Agent

**Focus:** human-reviewed coding workflows, controlled execution, validation, and proposed repository changes.

**Research questions:** Which validation and human-review boundaries make agent-assisted software changes safer and more auditable?

## Generative AI for Fraud Detection

**Focus:** generative modelling, supervised fraud detection, explainability, and risk analysis.

**Research questions:** Can generative approaches improve detection of difficult fraud patterns while retaining interpretable decision evidence?

## LinguaSpeak

**Focus:** speech recognition, translation, text-to-speech, and accessible language interfaces.

**Engineering focus:** connecting multiple language-processing stages into a usable end-to-end application.

---

## Evaluation mindset

For research-oriented projects, the repository should make it possible to distinguish between **a working prototype**, **an experimentally supported result**, and **a production-ready system**. Claims should be matched to the evidence available.
